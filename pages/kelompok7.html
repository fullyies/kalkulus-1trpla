7.1 Menentukan titik maksimum dan minimum

Materi — Titik Maksimum Dan Minimum
Di Dalam kalkulus, turunan digunakan untuk melihat perubahan suatu fungsi dimana suatu fungsi kita dapat menentukan
Titik Maksimum → nilai tertinggi
Titik Minimum → Nilai terendahnya

Contoh Soal

Soal:
f(x) = x² -4x + 3 ,
Tentukan titik minimum
dari fungsi ini

penjelasan Soal

[Langkah Pertama: Turunkan fungsi]
f(x) = x² - 4x + 3
f'(x) = 2x + 4
Lalu Cari Titik kritisnya
f(x) = 2x + 4 = 0
x = 2
f"(x) = 2

[Langkah Kedua:Lalu ubah x = 2]
f(x) = x² -4x + 3
f(2)= (2)² - 4(2) +3
= 4 - 8 + 3 = -1
Jadi Titik minimun dari f(x) = x² -4x - 3 adalah (2, -1)

Definisinya

Dalam kalkulus, titik maksimum dan titik minimum adalah titik pada suatu fungsi yang menunjukkan nilai terbesar atau terkecil dibandingkan dengan nilai fungsi di sekitarnya. Kedua titik ini sering disebut sebagai titik ekstrem.

7.2 Menentukan titik stasioner

Materi — Menentukan Titik Stasioner
Syarat Untuk Menghitung Titik Stasioner adalah dengan turunan pertama sama dengan nol
Titik stasioner juga dapat berupa maksimum lokal (puncak), minimum lokal (lembah), atau titik belok (inflection point) dimana fungsi tidak berubah arah.

Titik stasioner adalah titik pada suatu kurva di mana gradien garis singgung sama dengan nol. Dengan kata lain, pada titik tersebut kurva sesaat tidak naik maupun tidak turun sehingga garis singgungnya sejajar dengan sumbu-x.

Contoh Soal

Contoh Soal — Titik Stasioner

Soal:

[Diketahui fungsi :
f(x) = x² − 4x + 3
Tentukan titik stasionernya.]

Penyelesaian:

[Turunkan fungsi:
f′(x) = 2x − 4]
Cari nilai saat turunan sama dengan nol:
2x − 4 = 0
x = 2
Cari nilai fungsi
f(2) = 2² − 4(2) + 3
= 4 − 8 + 3
= −1
Jadi titik stasionernya adalah:
(2, −1)

7.3 Penerapan optimasi

Materi — Penerapan Optimasi
Optimasi dalam Kalkulus adalah metode untuk mencari nilai maksimum atau minimum dari suatu fungsi menggunakan turunan.
Langkah Umum Optimasi
Tentukan fungsi (model matematika)
Turunkan fungsi →
Cari titik stasioner →
Uji dengan turunan kedua Interpretasi hasil

Dalam matematika, optimasi bertujuan untuk mencari solusi yang paling efisien atau paling menguntungkan dari suatu fungsi. Nilai optimum diperoleh dengan menentukan titik stasioner (saat f′(x)=0) kemudian menguji apakah titik tersebut merupakan titik maksimum atau minimum.

Contoh Soal

Contoh Soal

Soal:

[Diketahui fungsi :
P(x)=−x^2+20x+5]

Penyelesaian:

Langkah 1:
Menentukan Turunan Pertama
Turunkan fungsi keuntungan terhadap x:
P′(x)=−2x+20
Langkah 2:
menentukan titik kritis
Set P′(x) = 0:
−2x + 20 = 0
x = 10
Dalam optimasi, nilai maksimum atau minimum terjadi saat:
P′(x)=0
Maka:
−2x+20=0 → Pindahkan 20 ke ruas kanan:
−2x=−20 → Bagi kedua ruas dengan -2:
x=10

Langkah 3:
Menghitung Keuntungan Maksimum
Substitusikan x=10 ke fungsi awal:
P(10)=−(10)^2+20(10)+5
P(10)=−100+200+5
P(10)=105

  1. Soal 1

    Misalkan
    f(x)=−x^2+4x+1
    Tentukan Apakah Fungsi Ini Titik Maksimum Atau Minimum

    Lihat Jawaban
    Langkah Pertama
    Turunan pertama
    f′(x)=−2x+4.
    Langkah kedua
    Titik Kritis diperoleh dari
    −2x+4=0
    x=2
    Langkah Ketiga
    Menentukan nilai fungsi
    f(2)=−(2)^2+4(2)+1=
    −4+8+1= 5
    Jadi Koordinat titiknya adalah (2,5).
    Karena turunan kedua negatif, maka titik (2,5) merupakan titik maksimum.

  2. Soal 2

    Diketahui fungsi
    f(x)=x^2−4x+3. Tentukan Titik Stasionernya.

    Lihat Jawaban
    Langkah Pertama
    Turunkan Fungsi Turunan Pertama:
    f′(x)=2x−4.
    Tentukan titik stasioner:
    2x−4=0
    x=2.
    Jadi Titik Stasionernya adalah 2

  3. Soal 3

    Sebuah perusahaan memiliki fungsi keuntungan K(x)=−2x^2+40x−100, dengan x menyatakan jumlah produk yang diproduksi. Tentukan Keuntungan Perusahaan Tersebut

    Lihat Jawaban
    Langkah Pertama
    Turunan pertama: K′(x)=−4x+40.
    Langkah Kedua
    Cari Titik Kritisnya(x)
    Menentukan titik Kritis:
    −4x+40=0
    x=10.
    Jadi Karena turunan kedua bernilai negatif, maka keuntungan mencapai nilai maksimum saat perusahaan memproduksi 10 unit.
    Keuntungan Maksimumnya Adalah
    Keuntungan maksimum adalah
    K(10)=−2(10)^2+40(10)−100 = 100.
